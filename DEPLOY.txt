# Deploy do Sistema de Bipagem

Use Node.js e PostgreSQL. Instale as dependências com `npm ci` e inicie com
`npm start`. Use HTTPS para o endereço servido aos usuários em produção.

## Variáveis de ambiente

- DATABASE_URL é a conexão PostgreSQL. Use um certificado confiável.
  Se o provedor usar uma CA própria, informe o PEM em DATABASE_CA.
- BOOTSTRAP_ADMIN_PASSWORD é a senha inicial do usuário admin, de 12 a
  256 caracteres. É obrigatória quando ainda não há administrador. Em
  instalações antigas, também permite substituir a senha padrão do admin
  na primeira inicialização. Remova a variável após ativar a conta.
- NODE_ENV=production ativa o cookie Secure fora do Railway.
- TRUST_PROXY_HOPS é o número de proxies confiáveis entre o navegador e
  o Node. No Railway, o padrão é 1. Em acesso direto, deixe vazio.
- PRODUCAO_URL e INTEGRACAO_TOKEN são necessários para sincronizar o
  catálogo com o serviço Produção. Configure o endereço HTTPS da sua
  própria instância antes de ativar essa integração.

## Atualização de uma instalação existente

Faça backup do PostgreSQL antes do deploy. Todas as sessões antigas exigirão
novo login. Senhas antigas migram para scrypt no login. A senha padrão antiga
do admin fica bloqueada e pode ser substituída via BOOTSTRAP_ADMIN_PASSWORD.

As permissões de impressão são vinculadas a cada envio. Para arquivos antigos
com etiquetas repetidas de outro envio, envie o arquivo de novo antes de
baixar essas etiquetas.
